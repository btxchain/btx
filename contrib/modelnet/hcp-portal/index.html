BTX Hosted Control Plane — reference portal

Catalogue and pairing shell. Not a wallet, not a CEX, not a consensus client. Isolated REGTEST / loopback lab only.

Browser cannot possess custody keys. This page never holds wallet seeds, ML-DSA spend material, or native wallet RPC. Access tokens, if typed, stay in this origin’s session fields — never in the URL bar, query, fragment, or pairing URI. Pairing is outbound-only (device dials out / polls). HTTP 202 is UNKNOWN, not settlement; this page never auto-submits a finance intent on 202, timeout, or lost response. Ranking copy is a catalogue annotation, not a protocol fact.

Catalogue / search

POST /capabilities/search. Hits may be empty (incomplete: true). Sponsored rank, trending, and quality claims are catalogue annotations (observed_at, coverage, freshness). They never become package identity, terms_id, funding authority, or local runtime admission.

Terms and funding quote

Exact IDs are protocol facts. Economy percents and “trending” copy are catalogue annotations. Quotes bind terms_id + atom strings. Unsigned fixtures confer no settlement.

Devices — outbound pairing

      
The device (local btx-hosted) creates its own pairing
        key and a short-lived challenge. This browser only displays identifiers and asks the
        authenticated account to approve that exact device. The device then dials out
        or polls GET /devices/{id}/handoffs. No inbound runtime port. No
        browser-to-unrestricted-localhost privileged route. No token in the pairing URI.
