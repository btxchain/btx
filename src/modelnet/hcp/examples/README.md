# Synthetic contract examples

All IDs, hashes, amounts, clocks, URLs and accounts are synthetic. `.unsigned.json` statements carry null signatures and confer no trust, native settlement or execution authority. The package references do not identify real model bytes. The examples deliberately report no native confirmation and no usable runtime. Use them only for schema/codec tests. Real ML-DSA/native/custody/runtime evidence must come from the integrated implementation.

The `https://exchange.example` and schema example domains are documentation placeholders, not services to contact.
