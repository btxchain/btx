This is the community runbook: **what 0.34 implements so a malicious actor
cannot hijack or stall the network as we open block production, and what
operators must still do.** A unit test is not a live fleet. Do not treat
“this binary compiled” as “mainnet is safe.”

## 0. Roles (read this first)

| Role | Flag | What makes a block valid | What the pin does |
|---|---|---|---|
| **Independent consensus miner / full node** | `-matmulvalidation=consensus` | **This node ExactReplays** Profile 1 | Telemetry + GETMMATTEST serve. Does **not** skip GPU. Does **not** steer `FindMostWorkChain` unless this process also holds a local signer WIF (lost-twin recovery). |
| **Trusted CPU archive (light client)** | `-matmulvalidation=trusted` | Pin quorum **replaces** ExactReplay above Profile 1 | The pin **is** MatMul PoW authority for *this* node. Stolen WIF = hijack of *this* archive. |
| **GPU attestor (signer)** | consensus + `-matmulattestationsignerkeyfile` | ExactReplay, then sign | Signs hashes this node already replayed. Must not be the archive’s only skip key. **Not a public seed.** `-discover=0`; never in DNS/`addnode`. |
| **Discovery relay (public DNS/addnode)** | `-matmulvalidation=relay` | **Nothing** — not a chain oracle | Must not load a pin. ADDR only (`NODE_MATMUL_DISCOVERY`). Never GETMMATTEST. See [`0.34-discovery-relay.md`](0.34-discovery-relay.md). |

Open attestor keys (`-matmulopenattestors`) are a **directory**. They are
never `HasQuorum`. Heard `MMATTEST` never moves BestKnown, the signed
frontier, or GETDATA.

Hard test: if removing every attestation signature does not change which
blocks an independent consensus node connects and mines, the feature is
gold-standard compatible. If `HasQuorum` means “block is valid” on that
node, it is Liquid; reject.

## 1. Hijack mitigations 0.34 actually enforces

### 1.1 Mainnet trusted mirrors require M=2

Above Profile 1, trusted mode does not accelerate ExactReplay. It
**replaces** it (`SkipExactReplayForGpuAttestation` = trusted mirror ∧ pin
quorum). A 1-of-1 or 1-of-N quorum is a single stolen WIF minting fake work
on every archive that follows that pin.

**0.34 fail-closed:** `AppInitParameterInteraction` refuses mainnet
`-matmulvalidation=trusted` when `N<2` or `M<2`
(`MainnetTrustedMirrorRefusesSingleKey`), unless the operator passes
`-allowsinglekeytrustedmirror=1` (logged, alarming, transition only).

Regtest and testnet keep 1-of-1 so harnesses stay single-signer.
Consensus+pin is **never** refused for 1-of-1: the pin is telemetry, not
skip.

The published live pin is still **1-of-2** (`matmultrustedthreshold=1` with
two pubkeys). That topology:

- **Starts** on consensus miners (warning: configure M=2 before the same
  keys are used on a trusted archive).
- **Refuses** on a 0.34 trusted mainnet archive.

**Before running this binary as a trusted archive:** raise the pin to
`-matmultrustedthreshold=2` *and* confirm both attestors sign every height,
**or** pass the override only for a named transition window. Do not leave
public CPU seeds on T=1 trusted after this binary.

RPC: `getmatmultrustedstatus.single_key_trusted_authority` must be `false`
on every production trusted archive. `single_key_pin` is `true` on today’s
consensus miners until the M=2 ceremony; that is telemetry exposure, not
ExactReplay skip.

### 1.2 Collocated miner WIF

A GPU attestor in an **M≥2** pin is the intended topology. A trusted
mirror that also holds a pin WIF, or a consensus miner whose WIF is the
**only** pin member, is a hijack amplifier: one stolen keyfile buys
`SignAuthoritative` and, on a trusted mirror, ExactReplay skip
(`CollocatedSignerPinIsHijackAmplifier`).

0.34 logs an InitWarning on mainnet. RPC:
`getmatmultrustedstatus.collocated_signer_pin`. Prefer a distinct M=2 pin
from the miner WIF. Keyfile `chmod 600`. Never put the signer WIF in
`btx.conf` (`-matmulattestationsignerkey` is itself a warning).

### 1.3 Open keys cannot hijack fork choice

- `HasQuorumLocked` = pin votes only (`PinQuorumLocked`).
- `IsAuthoritySigner` = pin members only.
- `ShouldAdvanceBestKnownFromMmAttest` is Accepted/Duplicate only.
- `PinSteersFindUniqueCompetingAttestedIndex` is trusted-mirror **or**
  local signer. Consensus+pin with no WIF cannot be steered by a foreign
  pin.
- Do **not** require `HasLocalSignature` for local-signer FindUnique
  (that re-broke 2026-08-17 miner recovery).
- Do **not** cap signed-frontier FindUnique at park depth (that stalled
  2026-08-16 archive catch-up).

### 1.4 Blocklist is fail-closed and manual

`-matmulattestationblocklist` / `addmatmulattestationblocklist` excise a
compromised pin key. Startup refuses if unblocked pin members drop below
M. The blocklist is **never** filled from peer counts, Heard size, or
“observed majority.” That would be Sybil (cheap keys). See
[`0.34-attestor-key-blocklist.md`](0.34-attestor-key-blocklist.md).

Open attestors default **off**. If you enable them, do not set
`-matmulopenthreshold=1` on mainnet (InitWarning): a single admitted GPU
key would then satisfy open quorum *signal*. Open quorum still does not
skip ExactReplay on consensus nodes.

### 1.5 Dump-and-run (rented hashpower) is closed on the default profile

Emergency PARK at depth **6** refuses a 151-block rewrite before
`ConnectTip`. Parked branches do not re-spend ExactReplay. Stall-recovery
199299 is 1/1 inherit, not a dump. ASERT floors at F from 191714. A freeze
does not retarget.

**Do not** set `-reorgprotectionprofile=archive` or `-parkdeepreorg=0` on
nodes that must resist dump-and-run. Check `getmininginfo` /
`getfinalityinfo` `park_depth` (expect 6 on emergency). Details:
[`0.34-dump-and-run-reorg.md`](0.34-dump-and-run-reorg.md).

Post-attacker freeze at *pumped* bits is broken by grinding or an operator
1/1 flag-day, **never** by an automatic dump.

## 2. Stall mitigations 0.34 actually enforces

### 2.1 Reserved AuthenticatedTipChild ExactReplay slot

Competing body-holding ExactReplay jobs must not fill the RC pending cap
and delay honest tip-children (freeze-DoS M1 feeding ASERT easing).

`CanStartCompetingMatMulRCVerification` leaves
`MATMUL_RESERVED_AUTHENTICATED_TIP_CHILD_SLOTS` (1) of the RC pending cap
free. `AdmitMatMulBlockVerification` and header speculation pass
`direct_authenticated_tip_child` / `authenticated_tip_child`. On the
production default (one RC job, cap == work-units) competing ExactReplay
**cannot start**; only an authenticated tip-child may occupy the device.

This does not change `nMatMulRCMaxPendingVerifications` (consensus param).

### 2.2 What still cannot freeze UpdateTip (already closed)

- Parked dump-and-run branches skip ExactReplay
  (`MatMulMaySpendExactReplayGpu`, `IndependentConsensusMaySpendExactReplayGpu(..., on_parked)`).
- Independent consensus keeps unattested competing twins off the GPU.
- GETMMATTEST is token-bucketed; aggressive hammer → Ban.
- Heard never moves BestKnown / GETDATA.
- One stolen pin vote does not raise the signed frontier (quorum-gated
  `NoteAcceptedAttestationHeight`) and does not jam `SignLocal` on the
  remaining honest attestor.
- FMWC skip budget 128; attested-frontier hint window 512.
- Header-PoW remains disabled (`nMatMulHeaderPoWDiscountBits == UINT32_MAX`).
  Do not enable it as a substitute for ExactReplay (audit C1 still open).

|---|---|
| `trusted_mirror` | `true` only on CPU archives that accept the Liquid-shaped contract |
| `single_key_trusted_authority` | **`false`** on every mainnet trusted archive |

| `unblocked_pin_members` | **strictly greater than** `threshold` (a spare key) |

  `single_key_trusted_authority`, or `collocated_signer_pin`.

  `on_active_chain` stays true → stranded competing attested fork.
- InitError: “Mainnet trusted MatMul mirrors require at least 2 independent

## 4. Rollout so 0.34 does not split the fleet

Order (do not skip):

1. **Independent consensus miners ExactReplay.** Pin is optional telemetry.
   Public miners may join here. Their WIF is not the archive pin.
2. **M=2 ceremony** for the published pin. Both attestors sign. Confirm
   `getmatmultrustedstatus.threshold=2` and both pubkeys on a staging
   trusted archive *before* any public-miner announcement that archives
   will follow those miners via skip.
3. **Trusted CPU archives** run this 0.34 binary with M=2 (no override).
   0.33.4 archives remain peers; they still accept T=1. Do not mix “0.34
   trusted T=1 override” and “0.34 trusted M=2” as if they were the same
   light-client contract.
   **Ceremony detail:** raising M 1→2 changes `AuthorityNamespace` (the
   durable DB prefix). Old attestations stop counting. Mirrors must
   re-collect quorum for the live tip (or `submitmatmulattestations` a
   bundle) immediately after rotation, or every archive stalls for the
   gap. Rotation is prospective; do not expect historical skip bits to
   migrate.
   **Mixed-fleet skip:** 0.33.4 `SkipExactReplayForGpuAttestation` followed
   the pin for *any* role. 0.34 skip is trusted-mirror × pin-quorum only.
   Upgrading consensus nodes before M=2 *contains* a compromised T=1 pin
   (0.34 ExactReplays; 0.33.4 may follow the stolen attestation). That
   split is a property of upgrading before the ceremony, not an accident.
4. Open attestors stay **off** until Epoch C research exists. They are
   not a path to sunset the pin. Do not copy `admitted_open_pubkeys` into
   the pin.
5. Attestor sunset is later (`0.34-release-phases.md` §6). Epoch C is not
   this branch.

0.33.4 peers keep working: 182-byte header, same P2P budgets, same
trusted-mode semantics on 0.33.4. 0.34 adds fail-closed M=2, reserved GPU
slot, park-aware ExactReplay skip, blocklist, and this runbook.

## 5. What 0.34 does **not** close (accept with documentation)

These are residual trust boundaries, not “forgotten bugs.” Do not “fix”
them with consensus-param reseals, auto-51% from gossip, or SNARKs.

| Residual | Why it stays |
|---|---|
| Permissionless ExactReplay majority can still out-mine the honest tip (tip-extension, park depth 0) | Inherent PoW. PARK 6 stops the *rewrite* shape, not a sustained out-pacer. |
| Shallow 1–5 block races at the F floor | Below PARK depth. First-seen + next honest child. |
| Stolen **T=1** pin on a trusted archive started with `-allowsinglekeytrustedmirror=1` | Operator accepted Liquid. Drop the override. |
| Consensus miner whose WIF is the only pin member | FindUnique recovery is intentional; stolen WIF is SignAuthoritative. Use M=2. |
| Fresh IBD in the pre-F band `(186000, 191714]` | Historical. Do not reseal F/ASERT. |
| EncDr `nMatMulMaxPendingVerifications=16` on pre-RC heights | Historical IBD. Live Profile 1 uses the RC pending cap. |
| Header-PoW C1 | Still disabled. Enabling it does not authenticate MatMul chainwork. |
| Auto-51% from attestor/peer counts | Sybil. Rejected. |
| Succinct proofs / Epoch C | New research, later height. |
| msghand FMWC drain from a headers-only tower | Bounded per call; authenticated chainwork refuses it as a tip. |
