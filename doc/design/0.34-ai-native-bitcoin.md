# 0.34 gold standard: ExactReplay, not attestation

Design reference for `pr/0.34-open-attestor-framework`. Not consensus. Not
a release note (`CLIENT_VERSION` stays 0.33.4.x). Not a merge to main.
Referenced from `FindMostWorkChain` comments.

## 1. One-line rule

**Block production** is permissionless: anyone who can run header-bound
Profile 1 ExactReplay of the header-committed MatMul may produce blocks
(the Bitcoin analog of hashing). **Validity** is local: a full node accepts
a block because *this node* ExactReplay'd it, never because a secp key
signed. **Fork choice** is most authenticated MatMul work, not most
signatures. **CPU archives are honestly named light clients** (weak
subjectivity + pin) until Epoch C. **Attestations are a sidecar**
(Liquid-shaped stopgap for machines without a GPU): out of the 182-byte
header, out of `CheckBlock`, out of `HasQuorum` for independent miners.

Hard test: if removing every attestation signature does not change which
blocks this consensus node connects and mines, the feature is gold-standard
compatible. If `HasQuorum` means "block is valid", it is Liquid; reject.

BTX's scarce resource is Profile 1 ExactReplay of the header-committed
MatMul. Komargodski-style useful MatMul is why mining is GEMM; it is not a
light-client certificate. Sidecar ECDSA is maximally outsourceable
(Miller CCS 2015).

## 3. Remaining BTX residuals (honest)

**Hash-lottery residual.** At v4 heights the only *header-level* PoW check
is `CheckMatMulProofOfWork_Phase1`: `matmul_digest` is a self-declared
32-byte field, not a hash of the header. Audit F1
(`doc/btx-matmul-v4.2-header-pow-gate.md`): forged high-claimed-work
header towers are cheap until the body arrives. The C2 throttle
(`nMatMulHeaderPoWDiscountBits == UINT32_MAX`) stays **disabled**. C1
(throttle ≠ chainwork authentication) stays **open**. Do not enable the
gate as a substitute for ExactReplay. The mining grind on `nNonce64` after
computing the true product C' is honest: a rate limit on top of
header-bound useful work.

**Federation residual.** `-matmulvalidation=trusted` still replaces
ExactReplay with pin M-of-N; that is the documented CPU-archive contract,
not a full node. A public trusted-mirror seed can sit on the attested tip
while GPU attestors also see a headers-only competing tower. That is the
protection layer working.

`FindUniqueCompetingAttestedIndex` / `unique_abandon` is gated by
`PinSteersFindUniqueCompetingAttestedIndex`: trusted mirrors and local
signers only. Consensus+pin with no WIF ignores the pin for fork choice
(lost-twin recovery stays on nodes that actually sign).

**Live network (read-only snapshot, EncDr flag day).** Active tip at
stall-recovery height **199299** on GPU attestors and the public
trusted-mirror seed. Pin is **1-of-2**. Peer mix spans 0.29.7–0.33.4.
GPU attestors run consensus with a local signer. The public seed is a
trusted mirror, not a full node.

## 4. Architecture on this branch

### Roles

| Role | MatMul check | Pin may skip ExactReplay? | Pin steers FMWC/GBT? |
|---|---|---|---|
| Consensus, no pin | ExactReplay | no | no |
| Consensus + pin | ExactReplay | no | no (telemetry / directory) |
| Consensus + WIF | ExactReplay then sign | no | signer recovery only (`FindUnique…`, HeightOccupied) |
| Trusted mirror | pin quorum | yes, iff pin covers this hash | yes (weak subjectivity) |

Predicates:

- `SkipExactReplayForGpuAttestation(has_pin_quorum, trusted_mirror)` → skip
  iff **both**.
- `HistoricalExactReplayCoveredByPinQuorum(trusted_mirror, direct_quorum,
  frontier_covers)` → GETMMATTEST serve budget only. Direct pin quorum may
  skip CUDA regen on any role; signed-frontier ancestry only on trusted
  mirrors. A skip never writes `BLOCK_EXACT_REPLAY_VERIFIED`.
- `MayPersistTrustedReplayAttestationBit(trusted_mirror, pin_covers)` →
  trusted mirror and pin coverage of *this* hash. Consensus miners never
  persist `BLOCK_TRUSTED_REPLAY_ATTESTED` (that bit authenticates chainwork).
  Startup reconciliation keeps the bit only on a trusted mirror with pin
  quorum.
- `PinSteersFindUniqueCompetingAttestedIndex(trusted_mirror, has_local_signer)`
  → trusted mirror or local signer only.
- `MustDeferConflictingAttestedHeight` / FMWC overlay /
  `MatMulAttestedMiningParentRequired` → trusted mirror only.
- `PinMayVetoUnattestedTipChildGpu` → trusted mirror only. Consensus miners
  ExactReplay one unique unattested tip-child; competing pin quorum is not a
  GPU-admission oracle (`ConsensusMayClaimUnattestedTipChildBody`).
- `GetMmAttestIsConnectTipValidityGate` / `UnconnectedHaveDataMayKickAbc` →
  GETMMATTEST is a ConnectTip / ABC-kick gate only on trusted mirrors.
  Consensus miners kick ABC on HAVE_DATA without a signature.
- `KeepFetchingWhileUnconnectedHaveData` → mirrors need pin-covered
  catch-up; consensus miners need `BLOCK_EXACT_REPLAY_VERIFIED`, not an
  archive GETMMATTEST.
- `ArchiveServiceBitIsValidityRequirement()` → always false. The archive
  service bit is a body-store hint, never fork choice or a GETDATA gate.
- `ShouldAdvanceBestKnownFromMmAttest` → `Accepted`/`Duplicate` only.
  `Heard` never moves BestKnown, signed frontier, or GETDATA. Open re-relays
  stay `Heard` (not `Duplicate`); `NoteAcceptedAttestationHeight` is pin
  signers only.
- `HasQuorumLocked` = pin votes only. `IsAuthoritySigner` = pin members
  only. Open keys store as `Heard`; admit-on-pin-co-sign is directory.

`validation.cpp` consensus+pin no longer early-returns
`TRUSTED_SIGNER_QUORUM` as PoW. The `trusted_profile1` / `covered_fast_path`
skip remains gated on `-matmulvalidation=trusted`.

### Archives are not authority (what 0.34 can and cannot do)

**Eliminate archive *authority*** is the gold-standard hard test: if every
CPU archive disappeared, a GPU miner joining via discovery relays still
ExactReplays independently and does not treat archive `getbestblockhash` /
GETMMATTEST as validity.

That is **not** "eliminate archives as a body store" and it is **not**
"CPU phones become full nodes." Epoch C (succinct proofs) stays later.

| Already true for consensus miners | Still archive-shaped (honest) | Must not do |
|---|---|---|
| ExactReplay is validity; pin skip is trusted-mirror only | CPU archives are pin light clients until Epoch C | Open keys as `HasQuorum` |
| FMWC/GBT pin steering is trusted-mirror only | Signers may GETDATA bodies from any `NODE_NETWORK` peer (data, not validity) | SNARK/header-PoW as ExactReplay substitute |
| Unique unattested tip-child ExactReplays even if archives signed a sibling | Historical IBD of the whole chain still needs a GPU or assumeutxo | Reseal EncDr/ASERT/F |
| Discovery-relay ADDR watermark may be raised by public miners, not only archives | Public DNS hosts must actually *run* as relays (operator roll) | Treat peer counts as fork choice |

Cannot claim 0.34 is "fully decentralized for every device." A machine
without a GPU cannot measure authenticated MatMul work. It follows the
compiled assumeutxo pin for history and the operator pin for the tip.

### Open speak (Slice B, salvage)

Open attestors may gossip v2 statements (`-matmulopenattestors`, default
off). Co-signing a pin-quorum hash lists the key in `getmatmulattestors`.
Equivocation freezes an open key. Pin keys are not frozen (0.33 dual-twin
recovery). `mmatrefute` from **M pin members** blocks the *open-quorum
directory signal* on that hash; pin `HasQuorum` is unchanged. WindowReplay
is store-only experimental directory ping: it counts signed/heard echoes
and does **not** bind a GPU. Do not wire it into admission.

### Epochs

| When | Authority | Attestor role |
|---|---|---|
| 0.33.4.x / 0.34 | ExactReplay | Pin for CPU archives; open speak is directory |
| Public discovery relays | ExactReplay (archives follow GPU pin) | DNS/addnode hosts are ADDR-only; not authority |
| Epoch C | Succinct proof (later height) | Attestors optional |

Succinct proofs remain impossible until *new* research. Do not ship
SNARK/STARK/FlyClient/NIPoPoW as 0.34 consensus.

## 5. Light clients (what 0.34 must not claim)

A phone/CPU client cannot run Profile 1 ExactReplay, so it is **not a full
node**. Epoch A security is:

1. **Compiled pins for history:** checkpoints, assumeutxo table,
   `defaultAssumeValid`, `nMinimumChainWork`. Same moral status as Bitcoin
   assumeutxo. `loadtxoutsetattested` is trusted-mirror-only; consensus
   nodes use `loadtxoutset`.
2. **Live pin for the tip:** `-matmultrustedpubkey` / threshold, confirmed
   via RPC after joining. Heard, open quorum, and seed ads are telemetry.

A light client cannot measure "most authenticated MatMul work" without
replaying. Open attestors do not decentralize light clients. Header-PoW
does not authenticate them.

## 6. Non-goals

- Attestors in the 182-byte header or in `CheckBlock`
- On-chain attestor registry, FROST/BLS of the open set, EigenLayer as
  fork choice
- Open keys into `HasQuorum` or into the pin skip
- Header-PoW enabled by default or used as ExactReplay substitute
- Consensus param / ASERT / F / EncDr digest reseal on this branch
- `CLIENT_VERSION` 0.34; push; restart the live GPU attestor

## 7. Remaining work (not this landing)

Landed 2026-08-25 (round-3 MUST-FIX): FindUnique gated to
mirror-or-local-signer; historical reverify no longer writes
`BLOCK_EXACT_REPLAY_VERIFIED` from pin coverage; open-speak maps capped;
MMATREFUTE uses the MMATTEST token/verify budget and a known Profile-1
header gate; pin-refute veto of open quorum requires pin M; open-state
fsync debounced; `-matmulopenattestors` defaults to 0.

Landed 2026-08-25 (round-4 MUST-FIX): `BLOCK_TRUSTED_REPLAY_ATTESTED`
persists only on a trusted mirror when the pin covers that hash
(consensus+WIF serve-budget skip and Heard cannot mint authenticated
chainwork); startup reconciliation clears the bit unless the node is
still a trusted mirror with pin quorum; per-height and total
open-signed-entry caps; frozen-open set capped; MMATREFUTE P2P and
`submitmatmulrefutation` require a known Profile-1 header whose index
height matches the statement; consensus 1-of-1 init warning no longer
claims the pin steers FMWC/GBT; open Heard re-relays stay `Heard` and
do not mint signed-frontier hints (live Add/Sign and durable
import/load).

Still operator / later:

- **0.34 code:** mainnet trusted mirrors refuse N<2 or M<2 unless
  `-allowsinglekeytrustedmirror=1`. A live T=1 public seed (published
  1-of-2 pin) cannot start as a trusted archive on this binary. Raise the pin to M=2
  (both attestors sign) before any public-miner announcement that archives
  will skip ExactReplay on those signatures. Consensus+pin keeps T=1 as
  telemetry with a warning. Runbook:
  [`0.34-operator-safeguards.md`](0.34-operator-safeguards.md).
- **Do not enable** header-PoW as ExactReplay (C1 open). Live 199309 is a
  headers-only tower; authenticated chainwork already refuses it as a tip.

Stolen pin WIF on a trusted mirror is the documented trust boundary
(M≥2, no miner WIF, keyfile `chmod 600`). The manual attestation
blocklist is the emergency excision; **auto-follow of observed
attestor/peer majority is Sybil and is not implemented.**

**Dump-and-run (2026-08-10/11).** A rented-hashpower attacker cannot
repeat the historical loop under the default emergency profile: PARK at
depth 6 refuses the 151-block rewrite before ConnectTip; stall-recovery
199299 is 1/1 inherit, not a dump; ASERT floors at F (`0x1f0a3d70`) from
191714. A freeze does not retarget. Post-attacker freeze at *pumped* bits
is broken by grinding or an operator 1/1 flag-day, never by an automatic
dump. Do not set `-reorgprotectionprofile=archive` / `-parkdeepreorg=0`
on nodes that must resist this. Details:
[`0.34-dump-and-run-reorg.md`](0.34-dump-and-run-reorg.md).
