# v1.0 → v1.1 migration

Preserve the original 34 HCP operations and seven signed object schemas byte-for-byte. The copied baseline artifacts are exact source bytes where available; BASELINE_MANIFEST.json records them. The agent also has the original v1.0 package and the current private implementation.

1. Freeze the candidate fingerprint and complete current workers before shared edits.
2. Register one explicit Cognitive Reserve extension profile under the accepted HCP provider.
3. Keep the existing HCP body-ID formula and use exact new `V1_1` object names. Expand the reviewed name allowlist, including underscores, rather than changing old digests.
4. Add tenant/entity-scoped persistence and versioned migrations. Read and reconcile existing financial records throughout rollout.
5. Introduce UI/SDK features only after profile negotiation. Older clients retain base operations; no new reserve/committee action silently falls back to unrestricted funding.
6. Rerun the original 120 cases plus new cases and cross-version journeys. Compare exact base OpenAPI operations and signature vectors.
7. Rollback disables new creation/execution but preserves accepted obligations, holds, refunds, event/export access and local generation safety.

No Core v4, monetary fork, new token or mandatory per-inference fee is part of this migration.
