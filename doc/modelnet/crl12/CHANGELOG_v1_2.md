# What changes in v1.2

## Preserved

HCP/1's 34 operations and seven original signed types; v1.1's 50 operations and 18 signed types; existing financial intents, reserve formula, committee rules, custody reconciliation, native funding, Core v3 capability recipes, local grants, generation leases and provider exit behavior.

## Added

Nine neutral provider roles; explicit service bindings; role-scoped adapter manifests; institutional asset/rights/position/valuation records; metric definitions; direct/look-through separation; snapshot projections; import/export jobs; draft-only portfolio instructions; deterministic scenarios; scoped conformance and reconciliation breaks.

43 new routes and 18 new signed types are described in the contract catalogue. Three operational routes support bounded job status, cancellation and binary import staging. They are part of the new institutional layer, not alternative financial-execution routes.

## Deliberately not changed

No new `.btx` Core v4, no native monetary change, no company-named provider profiles, no implicit security issuance, no invented investment rights, no second ledger/downloader/runtime, no mandatory central provider registry and no remote inference marketplace.

## Documentation

Six standalone reading volumes; anonymous case studies; an institutional whole-portfolio integration model; neutral partner and UX guides; 160 new native cases; 20 journeys; reference code, schemas, SDKs, deployment and mapping templates. Research publisher attribution is kept outside operational code and profiles.
