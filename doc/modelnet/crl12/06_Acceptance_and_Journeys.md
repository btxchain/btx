# Evidence contract

For each case retain candidate fingerprint, binary hashes, test command, test-network/configuration identity, actor/scope, relevant before/after state, exact assertions and sanitized logs under `evidence/CR12/<case-id>/`. Run through registered production paths. Record unit, process, chain, browser and external-system evidence separately. A case is not PASS merely because a symbol or HTTP route exists.
