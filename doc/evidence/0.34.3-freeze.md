# 0.34.3 golden freeze

This commit is the freeze `F` for v0.34.3. It bumps
`CLIENT_VERSION_BUILD` to 3. Parent is
`8320fd7b` (0.34.2 seal). BUILD_RELEVANT relative to that seal:
`src/net_processing.cpp`, `src/pow.cpp`, `src/pow.h`,
`src/node/matmul_block_lifecycle.h`, `src/validation.cpp`,
`src/validation.h`, `src/rpc/blockchain.cpp`, `CMakeLists.txt`, and
the matching unit tests. The golden manifest must be remeasured.

This freeze lands the v0.34.2 consensus deadlock fix that never made
the tag: W1a (linear tip-child is authenticated even when
`nAuthenticatedChainWork < nChainWork`), W1b (reserve one job, not one
work-unit), G2 (parse inbound BLOCK/CMPCTBLOCK/BLOCKTXN/INV on
authority nodes), and Jpp-matata deferral hygiene. Regression:
`linear_tip_child_replays_when_authenticated_work_lags`.

It also refuses a reorg that would disconnect an assumeutxo snapshot
base (the 0.34.1 fork-rejoin `invalidateblock` of 199299 on a 199300
snapshot used to AbortNode). Regression:
`snapshot_chainstate_refuses_invalidate_below_base`.
