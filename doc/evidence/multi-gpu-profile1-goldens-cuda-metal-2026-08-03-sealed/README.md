# Sealed CUDA + Metal Profile-1 golden cohort (historical freeze)

Status: **historical, non-authorizing evidence.** The artifacts recorded
`complete_multi_gpu_match: true` at freeze `78a88af5`, but later
build-relevant changes invalidate that freeze for activation. The digests are
preserved as evidence of cross-provider agreement at that revision; they are
not the exact-final production manifest.

## Policy

Independent reproduction for Epoch-A production goldens is cross-GPU-backend
(CUDA and Metal) ExactReplay on identical frozen canary headers. HIP is optional
but must match if submitted. Portable CPU reproduction is not an accepted
independent path for this GPU-optimized chain.

  `41a071900c855ce8cba0930114e7ecded689684da500ffd35ed0b5244369c1ed`

Both generated by `contrib/matmul-v4/multi-gpu-golden-corpus.sh` from clean
checkouts at that commit, so its guards — revision resolution,
fingerprint-matches-revision, fingerprint-matches-HEAD, dirty-tree refusal — all
passed before either artifact was written. Harness binaries differ per
architecture, which is the point.

## Result

Eight canonical 182-byte production canary headers, nonces 1-8,
`matmul_dim=4096`. All eight ExactReplay digests and all eight frozen header
byte strings byte-identical across providers, verified independently of the
comparator. Both providers report **1,088 device calls** and
**1,129,198,441,725,952 device MACs**, zero CPU GEMM calls, zero CPU MACs, zero
fallbacks, ExtractMX self-qual PASS.

Mean episode wall: CUDA 33.302 s (Blackwell-class `sm_120`), Metal 28.007 s
(M4-class Apple silicon).

## Why this one supersedes the 2026-08-02 seal

The 08-02 cohort was valid for `d1aad85b`. Landing the trusted-mirror floor and
the replay-authority context binding changed `src/`, which changes the
fingerprint and invalidates it by design. This cohort is bound to the tree that
actually carries those fixes.

## What it closes, and what it does not

At `78a88af5` this closed the comparator's matching-corpora requirement for
that tree. It does not close the current production-golden gate: the exact
final build-relevant revision must be rerun on CUDA and Metal, and the ASERT
campaign must satisfy the current schema-2 provenance and fallback checks.
Only those new artifacts may populate
`CommittedRCProductionGoldenManifest()` or support ratification.

Two providers agreeing does not prove the absence of a common specification bug;
the portable oracle remains the dispute tool.

## Freeze discipline

Valid only for `78a88af5`. Any later commit touching `src/`, `cmake/` or the root
`CMakeLists.txt` invalidates it; the comparator refuses to re-derive against a
different checkout, by design. Regeneration costs roughly five minutes per
provider on warm build trees but must be done on both against the same commit.
